# Diagrams

Source-of-truth cho các sơ đồ Mermaid lớn. File `.mmd` nằm ở đây để dễ edit standalone bằng [Mermaid Live Editor](https://mermaid.live).

Khi update:

1. Edit file `.mmd` ở đây
2. Copy nội dung vào markdown trong `docs/explanation/c4/*.md`
3. Commit cả 2 trong cùng PR

Diagrams nhỏ (chỉ dùng 1 chỗ) thì viết trực tiếp trong markdown, không cần copy ra đây.
